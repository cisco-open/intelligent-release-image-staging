2. Device packages

IOx and IOS-XR devices install a deployment-neutral package. During onboarding IRIS separately copies this server's current certificate to the device. Certificate rotation requires re-onboarding affected devices, but does not require rebuilding their packages. Guest Shell keeps its existing onboarding flow.

This step cannot be completed from the console. The console container has no Docker socket, so it can detect a stale package but never rebuild one. Run the command below on the Docker host, then re-check.

3. Image verification

Confirms every staged image's hash against Cisco's Bulk Hash feed before it is trusted. Without at least one successful check, IRIS cannot vouch that a staged image is the genuine, untampered Cisco release.
