Cisco IOS-XE image staging with private peer delivery

IRIS

IRIS gets large Cisco IOS-XE images onto routers and switches faster by letting devices share downloaded image chunks with each other. Each device verifies the image and stops at staging.

How it works

The simple idea: devices help each other download.

With a normal file server, every device asks the server for the whole image. With IRIS, the server introduces the image and devices exchange the pieces they already have. The more devices participate, the more download capacity the fleet can contribute.

Devices fetch missing pieces from the server and from peers. Transfers resume, load spreads out, and each device verifies the final staged image.

01

Faster fleet distribution

The server no longer has to send every byte of a multi-gigabyte image to every device. Devices that have pieces can help other devices catch up.

02

Better fault tolerance

BitTorrent-style piece transfers can resume after interruption, and devices can fill missing pieces from more than one source once the swarm has content.

03

Safer change control

IRIS only stages the approved image. Install, activation, boot changes, and reloads stay outside the tool and under operator control. On an existing management VLAN (inband), IRIS also never creates, changes, or removes that VLAN, its SVI, gateway, routes, or VRF. Network attachment and VLAN ownership.

Workflow

Publish, assign, stage, stop.

Publish an image

The operator publishes one IOS-XE image. IRIS records the hashes and creates private swarm metadata for the fleet.

iris-publish /opt/images/iosxe/c9300/<image>.bin

Catalyst 9300 Guest Shell

Generate a per-device installer, bootstrap Guest Shell, and let EEM keep the staging agent alive.

  • Installs catalog trust material.
  • Runs the agent every 60 seconds.
  • Stages approved images to `flash:`.

Platforms

Same delivery model, platform-specific staging.

Catalyst 9300 devices use Guest Shell and stage to `flash:`. IE platforms use an IOx app and stage to `sdflash:`. Both paths download by swarm, verify on the device, and stop before activation.
